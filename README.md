# ShopIT App

A modern full-stack Inventory Management CRUD application built using React Router v7, TypeScript, Express.js, PostgreSQL, and Multer for image uploads.

This project was created mainly for learning how modern frontend and backend technologies work together in a real-world CRUD workflow.

---

# 🚀 Tech Stack

## Frontend
- React
- React Router v7
- TypeScript
- Tailwind CSS
- Axios
- Lucide React Icons

## Backend
- Node.js
- Express.js
- PostgreSQL
- Multer
- pg

---

# ✨ Features

- Add Products
- Edit Products
- Delete Products
- View All Products
- Product Image Upload
- Dynamic Dashboard Stats
- REST API Integration
- Responsive Dark UI
- Loader & Action based Routing
- File Upload Handling with Multer

---

# 📊 Dashboard Includes

- Total Products Count
- Active Listings
- Out of Stock Products
- Recent Activity Section
- Quick Action Panel
